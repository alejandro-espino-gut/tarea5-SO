## Compilación y ejecución

Para compilar el código debemos colocarnos en el directorio raíz de la práctica y ejecutar el comando

``` 
gcc cadena.c -o cadena
```

Y para ejecutarlo debemos hacer

```
./cadena <tamaño_pagina> <archivo_traza>
```

Para `<tamaño_pagina>` el número de bytes que tiene una página y `<archivo_traza>` la dirección donde está el archivo codificado con la traza de ejecución

En el caso del ejercicio 21 del libro, ejecutar con el siguiente comando desde el directorio raíz de la práctica:

```
./cadena 512 direcciones.txt
```
